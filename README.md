# Mini AI — Компактный ИИ-помощник для Google Chrome (Manifest V3)

Лёгкое расширение для Google Chrome и Microsoft Edge в компактном окне **360 × 400 px**.
Построено по принципу: **открыл → ввёл запрос → получил ответ → скопировал → закрыл**.

## Важное примечание при обновлении расширения в Chrome

Если вы ранее уже загружали расширение в `chrome://extensions`:
1. Скачайте обновлённый архив **«Скачать расширение (.zip)»** (версия `1.1.0`) и распакуйте его с заменой файлов.
2. На странице `chrome://extensions` нажмите круглую иконку **«Обновить» (↻)** на карточке расширения **Mini AI**, чтобы Chrome подхватил обновлённый `manifest.json` и `popup.js`.
